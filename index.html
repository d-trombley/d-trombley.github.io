Below you will find some AI-assisted workflows I have built.

  1. Invoice agent: checks emailed invoices against the PO and receipt.
  2. Collections worklist: reads each past-due customer's email.

Invoice agent

Live demo

This agent is designed to help an accounting team deal with processing vendor invoices. It scans a connected email inbox and identifies which items have AP invoices. Then it either flags them as needing extra attention, or continues processing until it is review-ready for posting to the ERP. In this example we have a direct API integration into the ERP, but oftentimes in real-world scenarios a CSV upload file is the output.

Collections worklist

Live demo

This agent is designed to help an AR team work through past-due accounts. It starts from the aging report and reads each customer's email history before deciding what to do next, so it doesn't chase a customer who has disputed the invoice, already mailed a check, or is experiencing financial hardship. For each customer it either drafts the right reminder or holds the account for a person to look at. A person checks each email before it goes out, and final notices also need sign-off from a second person. In this example the customers and emails are made up, but in a real setup it would connect to the team's AR inbox and other data sources.
